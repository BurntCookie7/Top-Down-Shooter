## About

This is a top-down roguelike shooter built in Godot. Fight through waves of enemies, scrounge ammo and grenades, and earn upgrades at benches between rounds. Clear enough rounds and the map cycle loops, every run is a test of how long you can keep going.

## Features

- **Aim-to-shoot combat** with limited ammo, reserves, and manual reloading
- **Grenades** for stronger attacks
- **Enemies that follow you** and shoot back
- **Roguelike progression:** clear a round, sit at a bench, and pick an upgrade before the next map
- **Looping map cycle** runs keep going as long as you survive
- **Dynamic lighting** muzzle flash and lit sprites
- **Two control schemes:** mouse turning or keyboard turning, with adjustable turn sensitivity
- **Arachnophobia mode** for players who would rather not see the spiders

## Installation

### Run from source

1. Download the source code
2. Extract the zipped file
3. Open the project.godot file

**Requirements:** Godot [4.7.2], [Windows, Mac, Linux (Any OS Godot 4.7.2 supports)]

### Run from Compiled

1. Download the latest build
2. Extract the zip file
3. Run the windows.exe file

## Controls

| Action | Key / Button |
|---|---|
| Move | WASD |
| Turn (Mouse Turn mode) | Mouse |
| Turn (Key Turn mode) | A and D |
| Sprint | Shift |
| Aim | Right Click |
| Shoot | Left Click (while aiming) |
| Reload | R |
| Throw grenade | Q |
| Interact | E |
| Pause / settings | Esc |

You can switch between Mouse Turn and Key Turn, and adjust turn sensitivity, in the settings menu.

## How to Play

1. Defeat every enemy that spawns
2. Ammunition and grenades can be picked up after spawning around the map or being dropped by killed enemies
3. After defeating every enemy, sit down at a bench and choose an upgrade
4. The only way for a run to end is to die, gain power, and survive as long as possible
