# Top-Down-Shooter
A Top Down Shooter Made in Godot for Hack Club Terra. This project is fairly bare bones so it is missing some things
Expect the game to be kind of boring with little to no real content or replay value.

## Latest ##
Currently there are 2 different maps. "Maze" and "four corners" (when you press the play button it will
take you to a level select screen, just select the only available level named "test")


# How To Play
1. Download the file in Releases titled Build2.zip
2. Extract the file
3. Run windows.exe
